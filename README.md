# 🐶 Dogs – Rede Social para Cachorros

O **Dogs** é um projeto completo de uma rede social focada em compartilhamento de fotos de cães, permitindo que usuários publiquem, comentem, curtam e interajam. A aplicação foi construída com foco em boas práticas de arquitetura, desempenho, acessibilidade e experiência do usuário.

Link para o site: https://projeto-react-jade.vercel.app/
---

## 📸 Funcionalidades

- ✅ Cadastro e login de usuários
- ✅ Autenticação com JWT
- ✅ Upload de fotos com descrição e peso do animal
- ✅ Feed público com paginação
- ✅ Página de perfil com listagem de fotos do usuário
- ✅ Curtidas e comentários em fotos
- ✅ Proteção de rotas privadas
- ✅ Responsivo e acessível
- ✅ Validação de formulários
- ✅ Animações suaves de transição

---

## ⚙️ Tecnologias

- ⚛️ **React**
- 🧪 **React Router DOM** para rotas dinâmicas
- 🎯 **TypeScript** (caso aplicável)
- 📦 **Vite** como bundler
- 💾 **JSON Server** ou API REST própria
- 📸 **FormData** para envio de imagens
- 🔐 **JWT** para autenticação
- 🎨 css module

## 🔧 Como rodar o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/dogs.git
cd dogs
```

### 2. Instale as dependências

```bash
npm install
```

### 3. Inicie o frontend

```bash
npm run dev
```
